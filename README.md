# S / 50 — честный премиальный landing preview

Автономный адаптивный лендинг салона красоты в Ташкенте. Открывается напрямую через `index.html`; для полной проверки шрифтов и поведения рекомендуется локальный web-server.

## Что готово

- самостоятельная editorial-концепция без визуального копирования референса;
- mobile-first интерфейс для desktop/tablet/mobile без горизонтального переполнения;
- шесть оригинальных концептуальных фотосцен; мобильный hero отдан в AVIF с WebP-fallback;
- полноэкранный mobile hero с одним главным действием и адаптацией под 320–430 px;
- контекстная нижняя CTA появляется только после первого экрана и не перекрывает формы/футер;
- премиальная motion-система: staged hero, одноразовые reveal-маски и мягкие переходы формы;
- локальные Prata и Manrope без зависимости от внешнего CDN;
- доступное мобильное меню и пошаговый dialog предварительной заявки;
- обязательные услуга, дата, время, имя, телефон и согласие;
- понятные ошибки, success-state, системный Share и резервное копирование текста;
- честная коммуникация: форма не изображает подтверждённую запись;
- базовые local SEO meta-теги без выдуманных контактов и микроразметки;
- события `dataLayer` без персональных данных;
- reduced motion, keyboard navigation, focus trap и возврат фокуса;
- критический hero весит 44–45 KB; остальные изображения загружаются лениво.

## Перед публикацией обязательно заменить

1. Рабочий знак `S / 50` на утверждённый бренд.
2. Подтверждённые телефон, Telegram/Instagram, часы и точные координаты.
3. Реальный прайс, длительность услуг, специалисты и credentials.
4. Регламент стерилизации и характеристики лазера — только по документам.
5. Политику обработки данных и backend/CRM/Telegram-получателя для фактической отправки заявки.
6. Сгенерированные фото — на реальные фотографии салона после съёмки, если клиент хочет документальную аутентичность.
7. Production-домен, canonical, `og:image`, robots/sitemap и проверенную JSON-LD `BeautySalon`.

Форма намеренно не отправляет персональные данные во внешний сервис до подключения утверждённого получателя. Она формирует копируемую заявку и не показывает ложное подтверждение записи.
