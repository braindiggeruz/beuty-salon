# Lac & Nails Beauty Space — лендинг

Статический лендинг салона Lac & Nails (Ташкент, ул. Шота Руставели, 50).
Открывается напрямую через `index.html`; для полной проверки шрифтов и поведения нужен локальный web-server.

```bash
python -m http.server 4174 --bind 127.0.0.1
```

## Внешние сервисы

| Что | Куда ведёт |
| --- | --- |
| Онлайн-запись | `https://n659935.alteg.io/` (Altegio) — все CTA `.js-book` |
| Instagram | `https://www.instagram.com/lac_nails_uz/` — ссылки `.js-ig` |

Обе ссылки взяты из публичного профиля салона и проверены. Все цены, длительность
и свободное время живут в Altegio — на сайте цифр нет намеренно, чтобы они не устаревали.

## Что готово

- бренд Lac & Nails: логотип-лигатура `LN` + рукописное «Lac & Nails» собраны в SVG-контурах
  (`#ln-mark` в `index.html`, круглая версия — `assets/mark.svg`), перекрашиваются под тёмный и светлый фон;
- воронка замкнута: основной CTA ведёт в реальную онлайн-запись, форма подбора услуги
  предлагает выбрать время или написать в Instagram Direct;
- секция «Наши работы» — реальные фото работ салона;
- mobile-first интерфейс без горизонтального переполнения на 320–1920 px;
- полноэкранный hero на desktop и mobile с раздельными изображениями (AVIF + WebP fallback);
- контекстная нижняя CTA появляется только после первого экрана и не перекрывает формы и футер;
- премиальная motion-система; тяжёлые анимации убраны с LCP-элемента;
- локальные шрифты Prata и Manrope в WOFF2 с сабсетом (65 KB вместо 381 KB TTF);
- `BeautySalon` и `FAQPage` в JSON-LD, canonical, Open Graph с картинкой, `robots.txt`, `sitemap.xml`;
- `_headers`: CSP, `frame-ancestors 'none'`, HSTS, Permissions-Policy и кеширование ассетов;
- события `dataLayer` без персональных данных, включая `booking_click` и `instagram_click`;
- reduced motion, keyboard navigation, focus trap, брендированная 404.

## Перед публикацией на боевом домене

1. Подключить собственный домен и обновить `canonical`, `og:url`, `robots.txt`, `sitemap.xml`.
2. Добавить телефон (`telephone` в JSON-LD и видимый `tel:` в контактах) и часы работы
   (`openingHoursSpecification`) — сейчас их нет, потому что они не подтверждены.
3. Связать сайт с карточкой Google Business Profile и добавить `geo`-координаты.
4. Согласовать текст политики обработки данных и поставить ссылку в чекбокс согласия.
5. Заменить сгенерированные интерьерные сцены (`hero*`, `podology`, `laser`, `brows`, `consultation`)
   на реальные фотографии салона после съёмки. Фото работ в секции «Наши работы» — уже настоящие.
6. Решить, нужна ли узбекская версия и `hreflang`.

Регламент стерилизации, характеристики лазера и медицинские формулировки публиковать
только по документам клиента.

## Структура

| Файл | Назначение |
| --- | --- |
| `index.html` | лендинг, логотип-символ, форма подбора услуги, JSON-LD |
| `styles.css` | вся визуальная система, адаптивы, motion, состояния диалогов |
| `app.js` | меню, диалоги, подбор услуги, аналитика без PII, scroll-состояния |
| `404.html` | брендированная страница ошибки |
| `_headers` | заголовки безопасности и кеширования Cloudflare Pages |
| `assets/` | изображения, фото работ, шрифты WOFF2, логотип |
| `dist/` | папка деплоя, игнорируется Git — собирается из чистого дерева |
| `.env.deploy.local` | локальные токены, игнорируется Git |
